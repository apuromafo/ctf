 
# P.O.O. - Professional Offensive Operations

## Mission / Misión

**EN:** Professional Offensive Operations is a rising name in the cyber security world. Lately they've been working into migrating core services and components to a state of the art cluster which offers cutting edge software and hardware.

**ES:** Professional Offensive Operations es un nombre emergente en el mundo de la ciberseguridad. Últimamente han estado trabajando en la migración de servicios y componentes centrales a un clúster de última generación que ofrece software y hardware de vanguardia.

---

## What is P.O.O.? / ¿Qué es P.O.O.?

**EN:** P.O.O. is designed to put your skills in enumeration, lateral movement, and privilege escalation to the test within a small Active Directory environment configured with the latest and greatest operating systems and technologies. The goal is to compromise the perimeter host, escalate privileges and ultimately compromise the domain while collecting several flags along the way.

**ES:** P.O.O. está diseñado para poner a prueba tus habilidades en enumeración, movimiento lateral y escalada de privilegios dentro de un entorno pequeño de Active Directory configurado con los últimos sistemas operativos y tecnologías. El objetivo es comprometer el host perimetral, escalar privilegios y, finalmente, comprometer el dominio mientras se recolectan varias flags en el camino.

---

## Targeted Audience / ¿A quién va dirigido?

**EN:** P.O.O. is designed for penetration testers and red teamers in search of a quick and challenging lab in order to hone their engagement skills.

**ES:** P.O.O. está diseñado para penetration testers y red teamers que buscan un laboratorio rápido y desafiante para perfeccionar sus habilidades de compromiso (engagement).
