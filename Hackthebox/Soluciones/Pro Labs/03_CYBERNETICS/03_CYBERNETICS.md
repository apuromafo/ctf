# Lab 03: CYBERNETICS

## 🎯 Mission / Misión
Cybernetics LLC enlist the services of the player to perform a red team assessment on their environment. Cybernetics have gone through previous pentest engagements, iteratively hardening their environment each time, and therefore have a more mature security posture. Many protection technologies are present and the modern operating systems are fully updated. The enterprise in this real-world scenario focuses on Microsoft and DevOps/automation technologies.

## 🔍 Description / Descripción
Cybernetics is a captivating Windows Active Directory environment that has gone through various pentest engagements in the past, and therefore has upgraded Operating Systems, applied all patches, and hardened the underlying operating systems. As a result, the environment features current operating systems, with the latest patches and system hardening configuration applied.Cybernetics LLC, a robot manufacturing company, needs your assistance! You are a consultant that was brought in to perform a Red Team assessment on the Cybernetics environment. Your objective is to establish a foothold and pivot through the internal environment and acquire domain administrator privileges in all domains.

## 👤 Target / Objetivo
Cybernetics is ideal for seasoned penetration testers and professionals in Red Team settings. The lab was not designed for beginners - CVEs won

## 🛠️ Skills Required / Habilidades
- [ ] Familiarity with modern tools and techniques used to perform Penetration Testing engagements
- [ ] Strong knowledge of Networking and Web Application Attacks
- [ ] A good understanding of Linux and Windows Operating Systems and Active Directory
