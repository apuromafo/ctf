# Lab 05: APT

## 🎯 Mission / Misión
The company Mega Hosting has moved into the Managed Service Provider (MSP) business. The scenario involves initial compromise of a client, leading to compromise of the MSP infrastructure and all other clients. APTLabs simulates a targeted attack by an external threat agent against an MSP The lab requires prerequisite knowledge of attacking Active Directory networks.

## 🔍 Description / Descripción
APTLabs is an advanced challenge for red teamers that provides the opportunity to test multiple network attacks and TTPs (Tools, Techniques, Procedures). If you are ready for a tough, highly stimulating, and exciting hacking operation, go APT or go home! This advanced lab consists of fully patched servers, prevalent enterprise technologies, a simulated WAN network, and much more!

## 👤 Target / Objetivo
APTLabs is aimed at penetration testers and red teamers who have multiple years of experience. This enterprise network features vulnerabilities, misconfigurations, and attack paths seen in real engagements. It’s an excellent opportunity for players to level up their offensive tradecraft to the max.

## 🛠️ Skills Required / Habilidades
- [ ] A deep understanding of the Windows Operating System and Active Directory
- [ ] strong knowledge of network attacks
- [ ] Familiarity with modern tools and techniques used to perform penetration testing in enterprise environments

## 🏆 Learning Outcomes / Resultados
- [ ] Active Directory Enumeration and Exploitation
- [ ] Compromising Networks without using any CVEs
- [ ] Bypassing Common Security Features such as 2FA
- [ ] Exploiting Interactive Users
- [ ] Kerberos Attacks
- [ ] Lateral Movement
- [ ] Privilege Escalation
- [ ] Situational Awareness
