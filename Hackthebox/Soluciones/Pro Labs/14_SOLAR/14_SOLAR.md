# Lab 14: SOLAR

## 🎯 Mission / Misión
SolarSystem Space Prospection is an innovative young company whose primary mission is pioneering space exploration. While they set off to explore outer space, they want you to explore their infrastructure on Earth in order to assess its security.

## 🔍 Description / Descripción
Solar is designed to test your skills in Enumeration, Code Review, Pivoting, Web Exploitation and other attacking techniques. The goal is to gain a foothold on the internal network, escalate privileges and ultimately compromise the entire infrastructure, while collecting several flags along the way.

## 👤 Target / Objetivo
Solar is designed for advanced penetration testers who want to sharpen their skills in a unique environment filled with FreeBSD devices. It is ideal for those who enjoy tackling complex attack vectors, conducting in-depth research and enumeration, and mastering BSD-specific vulnerabilities like jail breakouts and advanced exploitation techniques. With a few Active Directory elements sprinkled in and challenges involving reverse engineering and rediscovering CVE’s, this lab also caters to those looking to push the boundaries of their knowledge and experience in niche operating systems and sophisticated security scenarios.

## 🛠️ Skills Required / Habilidades
- [ ] A grasp of penetration testing methodologies
- [ ] An understanding of the Linux and Windows operating system
- [ ] Basic knowledge of Active Directory
- [ ] Knowledge in web application attacks

## 🏆 Learning Outcomes / Resultados
- [ ] Enumeration
- [ ] Situational Awareness
- [ ] FreeBSD Exploitation
- [ ] Exploit Chaining
- [ ] Out-of-Band Data Exfiltration
- [ ] Web Application Attacks
- [ ] Source Code Review
