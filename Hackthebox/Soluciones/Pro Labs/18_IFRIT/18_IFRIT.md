# Lab 18: IFRIT

## 🎯 Mission / Misión
Ifrit is an IT services company that introduced a new security baseline recently. To evaluate its effectiveness, you have been tasked with performing a red team engagement on Ifrit’s internal networks.  In this case, the engagement will be performed as an assumed breach scenario and the company provided you with a list of users and passwords. To access the internal network, you will be able to log into a VDI environment.

## 🔍 Description / Descripción
Ifrit is a typical real world environment, designed to put your red team skills to the test. This lab is focused on operating covertly without triggering detection mechanisms.  You will be able to see detections in near real time and be able to tune your actions accordingly.

## 👤 Target / Objetivo
Ifrit is for people that already have basic knowledge in AD topics and pentesting and want to dive into red teaming.

## 🛠️ Skills Required / Habilidades
- [ ] A grasp of penetration testing methodologies
- [ ] Basic knowledge of Active Directory

## 🏆 Learning Outcomes / Resultados
- [ ] Network & Active Directory Enumeration
- [ ] Active Directory & Custom Exploitation
- [ ] Active Directory Certificate Services
- [ ] Lateral Movement across multiple Forests
- [ ] Bypassing EDR Solutions
- [ ] Relay Attacks
- [ ] Operating covertly
