> **ES:** Los retos de PicoCTF exigen cuenta en `play.picoctf.org` (verificado 2026-09-26: la plataforma devuelve 403 sin sesión; no se creó cuenta). Este archivo documenta el proceso para que el primer reto resuelto siga la plantilla.

## Proceso / Process

1. Elegir un reto General Skills estático (p. ej. `Obedient Cat`, `Python Wrangling`) y descargar su artefacto con sesión propia.
2. Resolverlo LOCALMENTE (sin atacar infraestructura fuera del reto).
3. Crear `PicoCTF/Solution/general-skills/<reto>.md` desde `../_PLANTILLA.md`: objetivo → comandos ejecutados → resultado/flag → fuentes + disclaimer + fecha.
4. Actualizar `PicoCTF/Solution/README.md` (contador 0 → 1) y marcar el ítem en `_PLANIFICACION/PENDIENTES.md`.
