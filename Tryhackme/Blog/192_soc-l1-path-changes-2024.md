# Exciting Changes to the SOC Level 1 Learning Path!

--------------------

Blue teamers - this one is for you!Today, 24th of July, the **SOC Level 1 learning path** received an exciting update, with 19 challenges added to the path to test your security analysis skills. To break this down, we’ve added 14 existing challenges, and 5 brand new challenges to get your teeth into!Not only this, but you’ll now be able to grab six brand-new badges with the updated path!All challenges cover topics taught in the SOC Level 1 learning path, including:
* Cyber Defence Frameworks
* Cyber Threat Intelligence
* Network Security and Traffic Analysis
* Endpoint Security Monitoring
* Security Information and Event Management
* Digital Forensics and Incident Response
* PhishingWe’ve also added four challenges in a separate capstone module, drawing from multiple modules from the path, and testing skills learned along the way.
## Why has this update taken place?
At TryHackMe, we believe practice is key to learning. By tackling these challenges, you’ll be able to further your incident detection and response skills, gaining a deeper understanding of SOC operations. This update underscores TryHackMe's commitment to offering you comprehensive and interactive training that equips you with the necessary skills to excel in the cyber security field!
## What does this mean for me?
If you’ve completed the SOC Level 1 learning path, you may now see the path marked as ‘incomplete’ in the dashboard. However, if you keep up with our regular challenge releases and have already completed the existing challenges to be added to the path, then you only need to complete the 5 new rooms released on 24th July: [TShark Challenge I: Teamwork](https://tryhackme.com/r/room/tsharkchallengesone?ref=blog.tryhackme.com), [TShark Challenge II: Directory](https://tryhackme.com/r/room/tsharkchallengestwo?ref=blog.tryhackme.com), [Monday Monitor](https://tryhackme.com/r/room/mondaymonitor?ref=blog.tryhackme.com), [Friday Overtime](https://tryhackme.com/r/room/fridayovertime?ref=blog.tryhackme.com), and [Retracted](https://tryhackme.com/r/jr/retracted?ref=blog.tryhackme.com).And if you want to refresh your memory before taking on the challenges, check out our [SOC Level 1 path!](https://tryhackme.com/path/outline/soclevel1?ref=blog.tryhackme.com)Launch SOC Level 1 path!
