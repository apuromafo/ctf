## What does the Cyber Security 101 path cover?
The NEW **Cyber Security 101 learning path** covers topics necessary for building a foundation in cyber security. Furthermore, it introduces valuable security tools for everyone, regardless of whether they continue with offensive or defensive security.Previously, the [Complete Beginner](https://tryhackme.com/r/path/outline/beginner?ref=blog.tryhackme.com) and [Introduction to Cyber Security](https://tryhackme.com/r/path/outline/introtocyber?ref=blog.tryhackme.com) learning paths were favourites for beginners and anyone starting with cyber security. We decided to merge the two paths to create the Cyber Security 101 learning path, combining 8 existing modules that have been completely revamped, with 5 brand new modules to ensure it is fully updated, refreshed, and easy to digest!
## What you will learn!
In the Cyber Security 101 learning path, you will learn:
* **Cyber Security Prerequisites: **Discover the main concepts, protocols, and techniques in cryptography and computer networking, and build a solid understanding of key technologies used in cyber security.
* **Cyber Security Required Skills: **Gain in-depth knowledge of different operating systems. Learn to use both Linux and Windows graphical and command-line interfaces.
* ******Offensive Security: ******Learn how penetration testers and red teams work. Discover the basics of exploitation, web hacking, and various offensive security tools.
* ******Defensive Security:** ****Discover how blue teams protect their organisations. Explore different defensive security tools and solutions.
* ******Career in Cyber Security: ******Acquire all the knowledge necessary to discover your passion for cyber security. Become prepared to choose and embark on a career in cyber security.
