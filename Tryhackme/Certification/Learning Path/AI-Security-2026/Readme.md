# AI Security (AI Security path) [AI1]

> **ES/EN** — Documentación del learning path oficial "AI Security" de TryHackMe (lanzado mayo-2026, cobertura OWASP LLM Top 10 + MITRE ATLAS).
> Documentation of TryHackMe's official "AI Security" learning path (launched May 2026, OWASP LLM Top 10 + MITRE ATLAS coverage).

Outline oficial / Official outline: https://tryhackme.com/path/outline/aisecurity
Landing del path / Path landing: https://tryhackme.com/aisecurity

### ¿Qué es? / What is it?

Path defensivo/ofensivo de seguridad en IA que parte de cero: cómo se construyen los sistemas de IA, dónde fallan y cómo defenderlos. Práctico (hands-on), nivel **Intermedio (Intermediate)**, orientado a carreras SOC/DFIR/Red Team con componente IA.

### Estructura (2026) / Structure (2026)

**25 rooms en 5 módulos** (un 6º room de lanzamiento "Ticketing Event" cuenta como orientación; terceros reportan 26 en total). Horas: **~40–60 h** según guía del examen AI1.

| # | Módulo / Module | Rooms |
|---|---|---|
| 01 | AI Fundamentals | 6 (AI/ML Security Threats, AI Models & Data, Prompt Engineering, AI Forensics, ContAInment CTF, +ticketing) |
| 02 | Secure AI Systems | 6 (Securing AI Systems, LLM Security, AI System Reconnaissance, AI Threat Modelling, AI Threat Modelling Assessment, +1) |
| 03 | Prompt Security | 4 (Prompt Injection, Jailbreaking, Prompt Defence, LLMborghini CTF / White Rabbit CTF) |
| 04 | AI Supply Chain Security | 4 (Understanding AI Supply Chains, Supply Chain Attack Vectors, Securing the AI Supply Chain, Payload CTF / Checkpoint CTF) |
| 05 | Data Poisoning | 5 (RAG Security Fundamentals, Data Poisoning in RAG, Sensitive Information Disclosure in RAG, UnIndexed challenge, Lockdown challenge) |

### Habilidades que valida / Skills validated

Prompt injection (directa/indirecta), jailbreaking (DAN, sufijos adversariales GCG, many-shot), RAG poisoning, exfiltración de datos de RAG, análisis forense de IA, supply chain de ML (Pickle RCE, backdoors), detección de backdoors en modelos (Neural Cleanse), frameworks: **OWASP LLM Top 10 (2025)**, **MITRE ATLAS**, NIST AI RMF, STRIDE/PASTA.
