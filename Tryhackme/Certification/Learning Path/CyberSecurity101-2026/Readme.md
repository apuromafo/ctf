# Cyber Security 101 (Cyber Security 101 path) [SEC1]

> **ES/EN** — Documentation del learning path oficial "Cyber Security 101" de TryHackMe (lanzado 21-oct-2024, versiones 2026).
> Documentation of TryHackMe's official "Cyber Security 101" learning path (launched Oct 21 2024, 2026 updates).

Guía oficial / Official outline: https://tryhackme.com/path/outline/cybersecurity101

### ¿Qué es? / What is it?

El **nuevo path de entrada** de TryHackMe que reemplaza a los antiguos "Complete Beginner" e "Intro to Cyber Security" (retirados 2025). Cubre fundamentos de ciberseguridad desde cero con enfoque práctico (hands-on), ofensivo y defensivo.

### ¿Cómo es la estructura? / How is it structured?

- **~54–56 rooms en 13–14 módulos**, con estimación oficial de **~45–46 horas**.
- Combina 8 módulos revampados de los paths antiguos con **5–6 módulos completamente nuevos** (incluye OWASP Top 10 edición 2025, añadido posteriormente).
- Temas: Linux, Windows/AD, redes, criptografía, explotación, web hacking, tooling ofensivo/defensivo, cripto, career pathing.
- Rooms marcadas Premium como *AI Security Path*, *Junior Analyst intro*, etc.

### ¿Termina en certificación? / Does it end in a certification?

**¡Sí!** Es la preparación oficial para la certificación **Cyber Security 101 (SEC1)**: https://tryhackme.com/certification/cyber-security-101

> Ficha local: [Cyber Security 101 (SEC1)](../Tryhackme%20SEC1/Readme.md)

### Datos de examen SEC1 / SEC1 exam facts (verificado / verified)

- **100 % práctico, sin preguntas tipo test** (fully hands-on, "no multiple-choice questions").
- **7 secciones**, escenarios reales Red/Blue/Purple sobre una analyst VM.
- Ventana de **24 horas** (timer continuo al iniciar) — **~60 min por sección**.
- **Open book, sin proctor**, evaluación por escenarios reales.
- **1 reintento gratis** incluido. 3 meses de Premium incluidos con la compra.
- Resultados inmediatos tras finalizar; certificado verificable con QR.
- Roles objetivo: Junior SOC Analyst, Level 1 Analyst, SOC roles entry.

### Puntaje de aprobación / Passing score

**PENDIENTE DE VERIFICAR** — las fuentes oficiales guardadas no muestran el pass mark exacto para SEC1. Las cifras que circulan (p.ej. "paso con 750/1000" o "455/700") corresponden a **SAL1**, NO a SEC1. No se documenta cifra hasta confirmarla en la propia página del examen.

### Precio / Pricing

Examen **$152** con 1 retake gratis; bundle Foundational (SEC0 + SEC1) **$177** (original $221). Precio verificado en la página oficial y referencial con información al **21.09.2026**. Premium se requiere para completar el path.
