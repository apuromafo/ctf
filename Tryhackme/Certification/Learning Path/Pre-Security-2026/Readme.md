# Pre Security (Pre Security path) [SEC0]

> **ES/EN** — Documentation del learning path oficial "Pre Security" de TryHackMe (revampado **18-feb-2026**; la versión anterior queda como Legacy).
> Documentation of TryHackMe's official "Pre Security" learning path (revamped Feb 18 2026; previous version tagged Legacy).

Guía oficial / Official outline: https://tryhackme.com/path/outline/presecurity
Versión retirada / Retired version (Legacy): https://tryhackme.com/path/outline/presecuritylegacy

### ¿Qué es? / What is it?

Path inicial de TryHackMe que cubre los fundamentos para empezar en ciberseguridad: desde redes y cómo funciona la web, hasta sistemas operativos, software y ataques/defensas. Es la base recomendada antes de cualquier otro path (Cyber Security 101, etc.).

### Estructura 2026 (7 módulos) / 2026 structure (7 modules)

| # | Módulo / Module |
|---|---|
| 01 | Introduction to Cyber Security |
| 02 | Network Fundamentals |
| 03 | How The Web Works |
| 04 | Computer Fundamentals |
| 05 | Operating Systems Basics |
| 06 | Software Basics |
| 07 | Attacks and Defenses |

- **~26–31 rooms** (el recuento exacto varía según fecha; se cruzó 26 rooms en varios recorridos 2026).
- Duración estimada: **~9–19 horas** según testimonios (la cifra oficial varía).
- El path nuevo añade **Software Basics** (binario/hex, Python/JS/SQL basics) y **Computer Fundamentals** (virtualización, cloud), junto a networking/OS con enfoque en ataques y defensas.

### ¿Termina en certificación? / Does it end in a certification?

**¡Sí!** Preparación oficial para la certificación **Pre Security (SEC0)**: https://tryhackme.com/certification/pre-security

> Ficha local: [Pre Security (SEC0)](../Tryhackme%20SEC0/Readme.md) — examen **$69** con 1 retake gratis. Precio referencial con información al **21.09.2026**.

### Datos de examen SEC0 / SEC0 exam facts (verificado / verified)

- **6 secciones** mapeadas a los 6 dominios del path; **10 preguntas por sección**.
- **45 min por sección**, ventana total de **24 horas**.
- **Sin proctor y open book**; preguntas prácticas/rellenar con entorno VM.
- **Aprobación con 390/600 (65 %)**.
- **1 reintento gratis** incluido.
- SEC1 es el paso siguiente (por encima de SEC0 en la ladder de certificaciones).
