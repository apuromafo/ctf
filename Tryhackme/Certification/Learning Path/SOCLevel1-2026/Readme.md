# SOC Level 1 (SOC Level 1 path) [SAL1]

> **ES/EN** — Documentación del learning path oficial "SOC Level 1" de TryHackMe.
> Documentation of TryHackMe's official "SOC Level 1" learning path.

Outline oficial / Official outline: https://tryhackme.com/path/outline/soclevel1

## ¿Qué es? / What is it?

Path defensivo que entrega las habilidades prácticas de un **SOC Analyst Tier 1**: triage de alertas, SIEM, phishing, monitoreo de red/endpoint, threat intel y respuesta a incidentes. Al completarlo se obtiene **Certificate of Completion** (requiere Premium) y quedas preparado para la certificación **SAL1**.

> Ficha local: [Security Analyst Level 1 (SAL1)](../TryHackMe%20SAL1/Readme.md)

## Estructura / Structure

**~42 rooms en 10 módulos**, estimación **40–60 horas** según experiencia:

| # | Módulo / Module | Contenido |
|---|---|---|
| 01 | Blue Team Introduction | Rol del analista SOC, Jr Security Analyst Intro |
| 02 | SOC Team Internals | Alert triage, alert reporting, estructura del SOC |
| 03 | Core SOC Solutions | EDR, SIEM (Splunk 101/201, ELK) |
| 04 | Cyber Defence Frameworks | MITRE ATT&CK, Cyber Kill Chain, Pyramid of Pain |
| 05 | Phishing Analysis | Fundamentos, emails en acción, análisis de headers/artefactos |
| 06 | Network Security | Snort, Zeek, TShark, tráfico de red |
| 07 | Endpoint Security | Windows Event Logs, Sysinternals |
| 08 | SIEM & Log Analysis | Splunk, ELK, correlación y detección |
| 09 | Incident Response | DFIR, Volatility, documentación y escalamiento |
| 10 | Threat Intelligence | IOCs, frameworks, inteligencia aplicada |

Actualización 2024-2025: +19 challenges (TShark CLI Wireshark, etc.); revamp mayor nov-2025.

## Certificación asociada / Associated certification

- **SAL1** — examen de ~5 h (80 MCQ + 2 simulaciones SOC), pass **750/1000**, **$299** con 3 meses Premium y 1 retake. Info al **21.09.2026**.
