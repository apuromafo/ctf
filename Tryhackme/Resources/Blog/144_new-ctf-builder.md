Our [CTF Builder](https://tryhackme.com/r/ctf-builder?ref=blog.tryhackme.com) is a brand new feature, enabling users to create a CTF event based on the 200+ CTF challenges which exist on the TryHackMe platform.Based on user insights, many teams value training events and CTFs. ## **Is there any set-up required?**
No! Everything you need from VMs to downloadable content is automatically added to the CTF. You can use the AttackBox or connect via VPN as you would any other room on THM. It’s as simple as that!
