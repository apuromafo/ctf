Breaking into cyber security has never been about a lack of information. Courses, videos, blogs, and tutorials are everywhere. The real problem has always been proving that you can actually do the work.
That’s exactly why we built the Cyber security 101 Certification , also known as SEC1 , is designed to validate real, foundational cyber skills, not just theoretical knowledge.
What Is the SEC1 Certification?
The SEC1 Certification is a hands-on, entry-level cyber security certification that acts as a capstone to the TryHackMe Cyber Security 101 learning path .
Instead of answering questions about cyber security, candidates perform real tasks in realistic environments. The certification validates foundational skills across:
Offensive security (Red Team)
Defensive security (Blue Team)
Investigative workflows
Everything happens inside TryHackMe’s browser-based labs.
Why We Built SEC1
Most beginner cyber security certifications follow the same pattern:
Heavy theory
Multiple-choice questions
Minimal connection to real job tasks
That approach doesn’t reflect how cyber security actually works and it doesn’t help learners stand out.We built Cyber Security 101 to solve 3 core problems we kept seeing across our community and the industry:
1. Beginner certs don’t reflect real work: Entry-level roles still expect hands-on ability: investigating alerts, interacting with systems, understanding attack and defence fundamentals. MCQs don’t measure that.
2. Learners wanted proof, not just progress: After completing the TryHackMe Cyber Security 101 path, learners consistently asked for a way to prove their skills, not just say they’d learned them.
3. There was a gap at the foundational level: Hands-on certifications exist, but they’re often expensive, advanced, or inaccessible to true beginners. SEC1 fills that gap with an affordable, practical option.
How the Exam Works
7 practical sections across:
OS & Network Fundamentals
Red Team (offensive)
Blue Team (defensive)
Entirely hands-on using TryHackMe’s browser-based labs:
Scenario-based tasks + accompanying technical questions for each section
No Multiple choice questions, every task requires user interaction and analysis
The exam runs over 24 hours, allowing learners to work through scenarios thoughtfully just like they would in a real role. Results are delivered immediately after completion, so there’s no anxious waiting.
