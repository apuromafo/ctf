## Contenido / Content

- **423 blogs** guardados (`001_` a `423_`), formato Markdown.
- Cada archivo incluye: título (H1), `**ID Original:**`, `**Slug:**`, separador de 20 guiones, cuerpo del artículo, sección `## Multimedia` (imágenes/videos cuando existen) y cita al pie con la URL del sitio.
- Imágenes descargadas para uso offline en `images/` (referenciadas como rutas locales).
- Los videos embebidos (Loom/YouTube) se conservan como enlaces al original.
