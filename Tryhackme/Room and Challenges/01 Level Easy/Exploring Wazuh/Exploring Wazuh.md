> **Objeto:** Explorar la plataforma Wazuh (SIEM/XDR) de extremo a extremo: arquitectura Agent/Manager, eventos de seguridad, integración con Sysmon y auditd, reglas, API REST y dashboard.

---

**Contexto:** Wazuh es una plataforma open-source de detección de amenazas e integral de seguridad que funciona como SIEM y XDR. Este room explora su arquitectura compuesta por Agents y Manager, la integración con Sysmon y auditd para monitoreo de eventos, reglas de detección, y la API REST para consultas programáticas. Se revisan alertas de seguridad generadas por los agentes configurados en el entorno.

> **ES:** Recorrido completo por Wazuh: componentes (Agents/Manager), análisis de alertas, Sysmon en Windows, auditd en Linux, ubicación de reglas, API REST y dashboard.
>
> **EN:** Full walkthrough of Wazuh: components (Agents/Manager), security alert analysis, Sysmon on Windows, auditd on Linux, rules location, REST API and dashboard.

**Metodología:** Se recorre la arquitectura de Wazuh desde su instalación y componentes (Agent y Manager) hasta su dashboard y API. Se practica la revisión de alertas de seguridad, la comprensión de eventos Sysmon en Windows y auditd en Linux, la ubicación de reglas de detección en el servidor, y el uso de la API REST con `curl` para consultas programáticas. ### Cadena de ataque / Attack Chain

Arquitectura Wazuh (Agent/Manager) → Análisis de alertas de seguridad → Sysmon (Windows/Event Viewer) → auditd (Linux) → Reglas de detección (`/var/ossec/ruleset/rules`) → API REST (GET/PUT con curl) → Dashboard (versión y agente más activo).

**Learning chain:** Wazuh architecture (Agent/Manager) → Security events analysis → Sysmon (Windows) → auditd (Linux) → Rule paths → API interaction (GET/PUT) → Dashboard analysis
