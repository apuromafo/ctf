**Contexto:** Room que exige haber hecho "Investigating Windows 1.0/2.0". Aporta **3 archivos** (snapshot estado de la máquina):
- `Logfile` — captura de **Procmon**.
- `WIN-Q5JJRDM876J` — captura de **Autorun**.
- `Sysmon` — capturas de **Sysmon** (exportadas a `.evtx`).

Tiene 30 preguntas. Laboratorio de DFIR: localizar el payload ofuscado en el registro, decodificarlo, seguir al agente malicioso (Empire/PSInject) y mapearlo a MITRE ATT&CK.

## Solucionario

### Task 1: El payload ofuscado en el registro

**Explicación:** Con Autorun se localiza el run key con el payload cifrado:

```
HKCU\Software\Microsoft\Windows\CurrentVersion\Debug
```

Sysmon generó para este run key la regla **T1547.001** (persistencia vía Registry Run Keys). Consultando esa técnica en MITRE ATT&CK, las tácticas asociadas son **Persistence, Privilege Escalation**. El evento correspondiente tiene timestamp UTC **2021-01-22 01:08:13.468**, Event ID **13** con Event Type **SetValue**.

| # | Pregunta | Respuesta |
| 1 | What is the registry key with the encoded payload? (full path) | `HKCU\Software\Microsoft\Windows\CurrentVersion\Debug` |
| 2 | What is the rule name for this run key generated by Sysmon? | `T1547.001` |
| 3 | What tactics is classified with this MITRE ATT&CK ID? | `Persistence, Privilege Escalation` |
| 4 | What was UTC time for the Sysmon event? | `2021-01-22 01:08:13.468` |
| 5 | What was the Sysmon Event ID? Event Type? (answer, answer) | `13, SetValue` |

### Task 2: Decodificar el payload

**Explicación:** Se extrae el valor Base64 del run key. Decodificando la primera capa:

```powershell
$payload = Get-Content .\payload.txt
[System.Text.Encoding]::ASCII.GetString([System.Convert]::FromBase64String($payload)) | Out-File -Encoding "ASCII" decoded_payload.txt
```

(en Linux: `cat payload.txt | base64 -d > decoded_payload.txt`). La primera línea revela que el payload intenta arrancar el servicio **Fax**, abrir el puerto local **9299** y terminar el proceso **FXSSVC**. Hay una segunda capa Base64 dentro del payload que revela qué DLL se intenta eliminar: **C:\Windows\System32\ualapi.dll** y una ruta parcial visible **/admin/get.php**.

| # | Pregunta | Respuesta |
| 6 | Decode the payload. What service will the payload attempt start? | `Fax` |
| 7 | The payload attempts to open a local port. What is the port number? | `9299` |
| 8 | What process does the payload attempt to terminate? | `FXSSVC` |
| 9 | What DLL file does the payload attempt to remove? (full path) | `C:\Windows\System32\ualapi.dll` |

---

### Task 3: El servicio Fax y PrintDemon

**Explicación:** La pregunta 10 es trampa: el servicio Fax no tiene logs obvios. `ualapi.dll` lo usa el servicio de impresión; buscando el log correspondiente se encuentra en `Microsoft-Windows-PrintService/Admin` el Event ID **823** ("The print spooler failed to load spooler printer driver" o fallo de driver). El evento muestra como **New Default Printer** el nombre **PrintDemon** y el proceso asociado es **spoolsv.exe** (PID raíz asociado al evento: el parent PID en Procmon es **620**).

El proceso que ejecuta el payload codificado (del run key) es el PID **3088**.

| # | Pregunta | Respuesta |
| 10 | What is the Windows Event ID associated with this service? | `823` |
| 11 | What is listed as the New Default Printer? | `PrintDemon` |
| 12 | What process is associated with this event? | `spoolsv.exe` |
| 13 | What is the parent PID for the above process? | `620` |
| 14 | Examine the other processes. What is the PID of the process running the encoded payload? | `3088` |

### Task 4: Identificar el framework de ataque

**Explicación:** Decodificando del todo el payload aparecen como rutas visibles y rutas de log entre procesos:

- Ruta parcial: **/admin/get.php**.
- Otras rutas en los logs: **/news.php** y **/login/process.php**.

Estas rutas son de **Empire** (framework de C2 para PowerShell). El perfil de comunicación por defecto del agente es la variable **DefaultProfile**, y su referencia MITRE correspondiente es [S0363 – Empire](https://attack.mitre.org/software/S0363/).

| # | Pregunta | Respuesta |
| 15 | Decode the payload. What is the a visible partial path? | `/admin/get.php` |
| 16 | This is the default communication profile the agent used to connect to the attack machine. What attack framework was used? What is the name of the variable? (answer, answer) | `DefaultProfile, Empire` |
| 17 | What other file paths are you likely to find in the logs? (answer, answer) | `/news.php, /login/process.php` |
| 18 | What is the MITRE ATT&CK URI for the attack framework? | `https://attack.mitre.org/software/S0363/` |

### Task 5: Conexiones al servidor del atacante

**Explicación:** Activando solo "Show Network Activities" en Procmon se ve el proceso sospechoso conectándose al FQDN del atacante:

```
ec2-34-245-128-161.eu-west-1.compute.amazonaws.com :9299
```

Otro proceso conectó también al mismo servidor: **Explorer.exe** con PID **2684**. Para el proceso identificado en las preguntas 19 y 20, la primera imagen cargada es **C:\Windows\System32\mscoree.dll** (indicio de la inyección .NET / PowerShell).

| 20 | What other process connected to the attacker machine? | `Explorer.exe` |
| 21 | What is the PID for this process? | `2684` |

### Task 6: Evento entre los dos procesos

**Explicación:** En el Sysmon, filtrando por los 2 PIDs, el evento generado entre ambos procesos es un **CreateRemoteThread** con Event ID **8**. El primer evento entre estos dos procesos ocurre en UTC **2021-01-22 01:07:06.182**, que en hora local es **1/21/2021 5:07:06 PM**. A partir de esa marca temporal, la primera operación del 2º proceso en Procmon es un **Thread Create**.

| # | Pregunta | Respuesta |
| 23 | What Symon event were generated between these 2 processes? What is its associated Event ID #? (answer, answer) | `CreateRemoteThread, 8` |
| 24 | What is the UTC time for the first event between these 2 processes? | `2021-01-22 01:07:06.182` |
| 25 | What is the value under Date and Time? (MM/DD/YYYY H:MM:SS [AM/PM]) | `1/21/2021 5:07:06 PM` |
| 26 | What is the first operation listed by the 2nd process starting with the Date and Time from Q25? | `Thread Create` |

### Task 7: Recopilación de información y módulo Empire

**Explicación:** La pregunta 27 es la más engañosa. Para "recopilar información de la máquina", el atacante consulta la clave de registro con la información de la versión del SO:

```
HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\ReleaseID
```

Al abrir "Event Properties" de ese evento de `QueryValue` (y con **Tools > Stack Summary** o la pestaña Stack Details), el último módulo del stack con resultado correcto es **\<unknown\>**.

El módulo del framework usado entre los dos procesos es **Invoke-PSInject** (inyección de PowerShell en memoria, típico de Empire). Esa técnica corresponde a MITRE **T1055 – Process Injection**.

| # | Pregunta | Respuesta |
| 27 | What is the full registry path that was queried by the attacker to get information about the victim? | `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\ReleaseID` |
| 28 | What is the name of the last module in the stack from this event which had a successful result? | `<unknown>` |
| 29 | Most likely what module within the attack framework was used between the 2 processes? | `Invoke-PSInject` |
| 30 | What is the MITRE ID for this technique? | `T1055` |

---

**Metodología:** DFIR / Incident Response sobre host Windows (triaje completo con Autorun + Sysmon + Procmon): correlación de eventos, decodificación en múltiples capas, seguimiento de red y mapeo a MITRE ATT&CK.

**Learning chain:** Run key ofuscado en `HKCU\...\CurrentVersion\Debug` → Sysmon 13/SetValue (T1547.001) → decode Base64 (Fax, puerto 9299, FXSSVC, ualapi.dll) → Event 823 PrintService (PrintDemon/spoolsv) → rutas `/admin/get.php` permiten identificar **Empire (S0363)** → conexiones a `ec2-...amazonaws.com:9299` desde proces + Explorer.exe → Sysmon 8 CreateRemoteThread → `mscoree.dll` → `Invoke-PSInject` → **T1055 Process Injection**.

**MITRE ATT&CK:** T1547.001 – Registry Run Keys / Startup Folder; T1055 – Process Injection (Invoke-PSInject); T1036 – Masquerading; T1071.001 – Web Protocols (C2 Empire); S0363 – Empire; T1219 – Remote Access Software; T1012 – Query Registry; T1041 – Exfiltration Over C2 Channel.
