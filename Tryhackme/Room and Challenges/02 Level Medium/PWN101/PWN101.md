**Contexto:** La sala **PWN101** es una colección de retos de explotación binaria para principiantes. Cada binario (`pwn101` → `pwn110`) enseña una técnica concreta: desbordamiento de búfer simple, ret2win, ROP, control de enteros, format string (printf sin formatear), ret2csu y encadenado de gadgets. La resolución se hace con Python y Pwntools y culmina con la flag del binario correspondiente.

**Metodología:** Para cada binario: análisis con `checksec` y desensamblado, identificación de la técnica (overflow, ret2win, ROP, enteros, format string), construcción del exploit con Python/Pwntools en local y remoto, y captura de la flag.

### Cadena de ataque / Attack Chain

```
Reconocimiento del binario (checksec / file / gdb)
        │
        ▼
Identificar primitiva (overflow, ret2win, fmt, ROP)
        │
        ▼
Construir payload con Pwntools
        │
        ▼
Explotar local y remoto
        │
        ▼
Flag del desafío
```

**Learning chain:** Análisis estático → identificación de primitiva → desarrollo de exploit → explotación → flag.

**Lección:** *La explotación binaria es incremental: cada reto (overflow → ret2win → ROP → format string → gadgets) apila una habilidad reutilizable; dominar Pwntools y la lectura de desensamblado resuelve el 90% de las salas de pwn.*
