> **Objeto:** Aprender a utilizar Threat Intelligence para mejorar el pipeline de Security Operations.

---
**Contexto:** **Threat Intelligence for SOC** es una sala guiada de dificultad Media centrada en cómo **consumir Threat Intelligence** para mejorar las capacidades de un SOC. Se distingue entre productores y consumidores de inteligencia, se trabajan los tipos de Threat Intelligence y se aplican IOCs reales. La parte práctica cubre la prevención (bloqueo por firewall, email gateway y **DNS sinkhole**) y la detección (traducción de reglas **Sigma** a **ElastAlert** con Uncoder.io), cazando los IOCs en una instancia de Kibana/ELK. Todo el flujo culmina en varias respuestas numéricas y de identificadores extraídas del análisis.
> **ES:** Aprende a utilizar Threat Intelligence para mejorar el pipeline de Security Operations.
> **EN:** Learn how to utilise Threat Intelligence to improve the Security Operations pipeline.

### Task 3: Prevención guiada por inteligencia / Intelligence-driven Prevention
**Explicación:** Como consumidor de Threat Intelligence, se despliegan controles preventivos. Se configura un **DNS Sinkhole** para el dominio malicioso `agrosaoxe[.]info` y se analizan los logs: número de consultas DNS, IPs resueltas antes del sinkhole, IP del sinkhole, hits originados por conexiones a dominios sinkholed y número de dominios únicos.

| What is the IP address used for DNS Sinkhole? | `192.168.5.13` |
| How many hits were caused by connections to sinkholed domains? | `115` |
| How many unique domains have been sinkholed? | `12` |

### Task 4: Detección guiada por inteligencia / Intelligence-driven Detection
**Explicación:** Se optimiza la detección a partir de IOCs. Se traduce una regla **Sigma** a **ElastAlert** con Uncoder.io, se despliega en el host y se analizan los resultados: el valor del campo `alert`, el número de alertas generadas, los dominios únicos sinkholed vía `0.0.0.0` y el dominio `.ru` sinkholed.

| Pregunta / Question | Respuesta / Answer |
|---------------------|--------------------|
| What is the value of the alert field in the converted ElastAlert rule? | `debug` |
| How many alerts were generated by the rule? | `40` |
| How many unique domains were sinkholed via 0.0.0.0? | `7` |
| What is the sinkholed domain that has .ru TLD? | `twizt.ru` |

### Cadena de ataque / Attack Chain
```
Introducción -> Threat Intelligence Feeds (IOC hunting en Kibana: 11 IPs, 48 hits, 7 IPs, 21 conexiones,
   host 10.10.196.49, puerto 80) -> Intelligence-driven Prevention (DNS sinkhole agrosaoxe[.]info:
   11 queries, 104.21.48.143/172.67.186.179, sinkhole 192.168.5.13, 115 hits, 12 dominios)
-> Intelligence-driven Detection (Sigma -> ElastAlert: alert debug, 40 alertas, 7 dominios 0.0.0.0, .ru twizt.ru)
-> Conclusión
```
**Learning chain:** IOCs → traducción a consultas → prevención (bloqueo/sinkhole) → detección (Sigma/ElastAlert) → respuesta.
**Lección:** *La Threat Intelligence solo genera valor cuando se convierte en controles de prevención y reglas de detección accionables.*
