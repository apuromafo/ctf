# Health Hazard (Riesgo para la Salud)

## Descripción general del escenario

Después de meses de hacer malabarismos con calendarios de contenido y lluvias de ideas impulsadas por la cafeína, el cofundador Tom Whiskers finalmente dedicó tiempo para crear el primer sitio web de la empresa. Se suponía que sería algo sencillo: seguir un tutorial, instalar unos cuantos paquetes y dar vida a la marca con algo de magia ligera en JavaScript.

Pero entre noches sin dormir y código copiado y pegado, Tom empezó a sentirse extraño. No enfermo exactamente, solo extraño. La terminal se desplazaba con un tranquilizador texto verde, el sitio cargaba bien y todo parecía normal.

Pero nadie sabe realmente qué podría haber estado oculto debajo de todo aquello…

Simplemente esperaba.

## Objetivos del escenario

* **Determinar el acceso inicial:** Determinar cómo un actor de amenaza obtuvo por primera vez un punto de apoyo en el sistema. Identificar actividad sospechosa que pueda señalar el método de compromiso inicial.
* **Investigar la ejecución maliciosa:** Investigar signos de ejecución maliciosa tras el acceso inicial. Analizar los registros y el comportamiento del sistema para descubrir las acciones del atacante.
* **Identificar persistencia:** Identificar cualquier mecanismo que el atacante haya utilizado para mantener el acceso a través de reinicios del sistema o sesiones de usuario. Buscar indicadores de persistencia que podrían permitir el control a largo plazo.
