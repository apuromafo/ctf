# 00_INICIAL / Initial Setup

> **ES:** Configuración inicial y notas neutras para DockerLabs.
> **EN:** Initial setup and neutral notes for DockerLabs.

## Objetivo / Purpose

Documentar el punto de partida: entorno, herramientas, convenciones y checklist para trabajar de forma ordenada con DockerLabs.

## Entorno / Environment

- Sistema: Windows + WSL/Linux (ajustar según uso)
- Docker Desktop / Docker Engine
- Git

## Checklist de inicio / Startup Checklist

- [ ] Verificar Docker funcional (`docker --version`, `docker ps`)
- [ ] Tener acceso a recursos de `dockerlabs/Resources/`
- [ ] Usar plantillas de `dockerlabs/Templates/`
- [ ] Seguir metodología en `dockerlabs/Methodology/`
- [ ] Mantener notas neutras, sin flags/credenciales

## Convenciones / Conventions

- **Nomenclatura:** usar nombres descriptivos, sin espacios problemáticos
- **Documentación:** ES/EN cuando aplique, conciso
- **Neutralidad:** evitar spoilers completos; priorizar metodología y aprendizajes
- **Referencias:** usar enlaces verificables, preferir fuentes oficiales

## Roadmap inicial / Initial Roadmap

1. Familiarizarse con el índice `dockerlabs_writeups_index.json`
2. Seleccionar laboratorio objetivo (propio) y documentar con `LAB_TEMPLATE.md`
3. Aplicar metodología paso a paso
4. Consolidar aprendizajes en `Labs/`
