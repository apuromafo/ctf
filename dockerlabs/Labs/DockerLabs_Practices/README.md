# DockerLabs — Prácticas y documentación propia

> **ES:** Documentación propia de laboratorios DockerLabs. Enfoque en metodología, aprendizajes y comandos, con citas a fuentes externas cuando corresponda.
> **EN:** Own documentation of DockerLabs exercises. Focus on methodology, learnings and commands, citing external sources when applicable.

## Directrices / Guidelines

- **Neutralidad:** No incluir flags, credenciales ni soluciones completas paso a paso en forma de "giveaway".
- **Aprendizajes:** Priorizar *qué*, *por qué* y *cómo validar* (comandos, técnicas, errores encontrados).
- **Citas:** Si se usa información de terceros (tutorial, artículo), incluirla en **Referencias/Anexos** al final de cada documento.
- **Plantilla:** Usar `Templates/LAB_TEMPLATE.md` para cada laboratorio documentado.
- **Idioma:** ES/EN cuando sea útil para claridad.

## Estructura sugerida / Suggested structure

Cada laboratorio en su propia subcarpeta:

```text
DockerLabs_Practices/
└── NOMBRE_LAB/
    ├── README.md  (usar LAB_TEMPLATE.md como base)
    └── notas/     (anotaciones, comandos, capturas si necesarias)
```
