# DockerLabs — Referencia cruzada

> **ES:** Referencia cruzada entre índices, máquinas y recursos para mantener coherencia.
> **EN:** Cross-reference between indexes, machines and resources to keep consistency.

## Índices disponibles / Available indexes

- `dockerlabs_writeups_index.json` (2784 entradas) — índice base del JSON original
- `dockerlabs_writeups_new.json` (172 entradas) — índice nuevo, más moderno

## Objetivo

Facilitar la identificación de patrones, evitar duplicados y orientar la selección de objetivos documentables con enfoque propio.

## Uso

1. Cruzar ambos índices por nombre/máquina
2. Identificar laboratorios con buena documentación externa para contrastar
3. Seleccionar candidatos para documentar con `Templates/LAB_TEMPLATE.md` en `Labs/DockerLabs_Practices/`
4. Registrar hallazgos neutrales y aprendizajes (comandos, técnicas, errores)
5. Si se cita fuente externa, incluirla en **Anexos / References** del writeup propio
