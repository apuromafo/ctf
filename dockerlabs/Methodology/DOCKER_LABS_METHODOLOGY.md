# Metodología Docker Labs / Docker Labs Methodology

> **ES:** Enfoque metodológico neutro para abordar laboratorios basados en Docker.
> **EN:** Neutral methodological approach for tackling Docker-based labs.

## Fase 1: Reconocimiento / Reconnaissance

1. Identificar el alcance y objetivos del laboratorio
2. Enumerar servicios expuestos y puertos
3. Analizar imágenes/contenedores (cuando sea propio)
4. Documentar superficie de ataque sin asumir soluciones

## Fase 2: Análisis / Analysis

1. Revisar configuración (Dockerfile, docker-compose, volúmenes)
2. Identificar permisos, capacidades y aislamiento
3. Detectar posibles malas configuraciones
4. Formular hipótesis verificables

## Fase 3: Validación / Validation

1. Probar hipótesis de forma controlada
2. Documentar hallazgos técnicos (neutrales)
3. Evitar registrar soluciones completas o credenciales

## Fase 4: Documentación / Documentation

1. Registrar aprendizajes y conceptos
2. Mantener referencias verificables
3. Seguir principios de documentación objetiva
