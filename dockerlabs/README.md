# DockerLabs

> **ES:** Documentación neutra y estructurada sobre Docker Labs, metodologías y ejercicios prácticos de aprendizaje.
> **EN:** Neutral, structured documentation about Docker Labs, methodologies and practical learning exercises.

## Objetivo / Purpose

Organizar material propio relacionado con Docker Labs. Este directorio **no se publica** (está excluido en `.gitignore`).

## Estructura / Structure

- `Methodology/` — Metodologías y flujo de trabajo (neutras, sin spoilers de retos específicos)
- `Templates/` — Plantillas reutilizables para documentación
- `Resources/` — Enlaces, referencias, índices cruzados y notas técnicas neutrales
- `Labs/` — Notas propias de laboratorios
  - `00_INICIAL/` — Configuración inicial y convenciones
  - `DockerLabs_Practices/` — Documentación propia (aprender, experimentar, registrar aprendizajes)
  - `DockerLabs_Reference/` — Referencia cruzada entre índices y recursos

## Directrices / Guidelines

- **Neutralidad:** Sin flags, credenciales ni soluciones completas.
- **Aprendizajes primero:** Enfocar en comandos, técnicas, errores y razonamiento.
- **Citas a terceros:** Si se cita tutorial/artículo, incluirlo en **Referencias/Anexos**.
- **Coherencia:** Usar `Templates/LAB_TEMPLATE.md` para documentación propia.
- **Verificable:** Priorizar fuentes oficiales o verificables.

## Notas / Notes

Todo el contenido sigue las directrices del repositorio (ver `_PLANIFICACION/AGENT.md`). Mantener enfoque metodológico, ordenado y reproducible.
